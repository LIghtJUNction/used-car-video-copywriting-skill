# Xian Shifu IP Profile

Use this reference when the user asks for `线师傅`, `线师傅二手车`, `行如云二手车`, hard off-road/commercial/pickup scripts, or IP-consistent used-car content.

## Core Positioning

- IP: `线师傅二手车`.
- Brand context: `行如云二手车`.
- One-line positioning: a product-driven used-car IP focused on `硬派越野 + 商用车 + 皮卡`.
- Content logic: vehicle first, persona second. The car is the protagonist.
- Trust anchor: `无越野史` for off-road vehicles, plus visible condition proof and third-party inspection language.
- Operating style: vertical, practical, industrialized, trust-oriented, search-friendly.

Do not write as:

- 泛娱乐 car influencer.
- 剧情/搞笑 account.
- Luxury lifestyle account.
- All-category car reviewer.
- Pure emotional storytelling account.

## Vehicle Focus

Prioritize these categories:

- Hard off-road: 帕拉丁, 帕杰罗, 牧马人, 普拉多, 吉姆尼, 坦途-like off-road inventory when facts support it.
- Commercial vehicles: 全顺, 依维柯, 五十铃, van and logistics-use vehicles.
- Pickups: practical-use and policy-aware pickup content.

If the provided vehicle is outside these categories, keep the `线师傅` style but do not pretend it belongs to the core niche.

## Title Formulas

Use direct, search-friendly titles. Prefer `price + model + proof/selling point`.

Patterns:

- Price anchor: `3万多预算，帕杰罗，不是事故，三方检测中`
- Scarcity: `全国少见没有越野史的四驱帕拉丁`
- Use-case: `创业拉货，几万预算看这台全顺`
- Anti-common-sense: `防弹帕拉丁，仅此一台，你见过吗`
- Story-light: `客户提帕拉丁，准备退休后跑山`

Keep titles concrete. Avoid clever but unsearchable titles.

## Voice And Catchphrases

Allowed style:

- Plain spoken Chinese.
- Short, concrete numbers: `2万多预算`, `4万多公里`, `3-8万预算`.
- Low-jargon condition explanation.
- Use rhetorical questions for interaction: `你们见过吗`, `这个预算你会怎么选`.

Useful phrases:

- `量大管饱`: use for abundant inventory only.
- `没有越野史`: use only when provided or supported by inspection/source facts.
- `车况板正`: use only with visible condition support.
- `三方检测`: use only when supported.
- `全国发货`: use only when logistics service is actually offered.
- `地库长大的车`: use only when source/storage facts support it.
- `情怀硬派越野`: use for nostalgic off-road vehicles when fitting.

Do not invent these claims. If not provided, say `需以检测报告/实际车况为准`.

## Shooting Flow

Default inventory video structure:

```text
00:00-00:03 Hook: rare model / low price / no off-road history / practical conflict.
00:03-00:12 Exterior: walkaround, paint, stance, tires, cargo/body condition.
00:12-00:22 Interior: wear, odometer, seats, dashboard, practical features.
00:22-00:35 Engine bay and chassis: visible proof, condition, leakage/rust notes if known.
00:35-00:45 Buyer fit and trust: who should buy, who should not, inspection/logistics CTA.
```

For short 15-25s videos, compress to:

```text
Hook -> exterior proof -> interior/engine proof -> buyer fit -> CTA
```

## Audience

Core audience:

- 30-50-year-old male buyers.
- 三线及以下城市, budget-sensitive and practical.
- 个体户,工程人员,越野爱好者,退休计划用户.
- Budget often `3-8万`; some entry buyers are `1-4万`.

Audience circles:

- 越野入门圈: wants 帕拉丁/帕杰罗 with limited budget.
- 工程商用圈: needs 全顺/五十铃 as production tools.
- 露营改装圈: buys 全顺/依维柯 for camper conversion.
- 创业代步圈: needs cheap, durable, load-capable cars.

Map pain points directly:

- Fear accident/off-road-abused car -> condition proof, `无越野史` only when supported.
- Limited budget but wants off-road -> price anchor and realistic tradeoffs.
- Local shortage -> national logistics if supported.
- Pickup policy anxiety -> discuss policy only when current and verified.

## Business And Conversion Style

Use transaction-oriented, not entertainment-oriented scripts.

- Main CTA: private message, ask for inspection report, reserve, test drive, logistics consultation.
- Avoid multi-CTA endings.
- Do not publish phone numbers or private contact details unless user explicitly provides them for output.
- Keep price and finance language conditional: `价格以当天报价为准`, `金融方案以实际审核为准`.

## Differentiation Rules

Compared with broad car influencers:

- Be small and specialized, not big and generic.
- Be product-driven, not persona-driven.
- Be transaction-oriented, not comedy/plot-driven.
- Be search-friendly, not purely recommendation-feed dependent.
- Use repeated standardized formats when generating batches.

## Generation Checklist

Before finalizing a `线师傅` script:

- Does the vehicle fit hard off-road, commercial, pickup, or practical used-car logic?
- Does the opening include price/model/proof/use-case rather than a vague greeting?
- Are claims like `无越野史`, `三方检测`, `全国发货`, `车况板正` supported?
- Is the car visually central in every scene?
- Is the language plain enough for practical buyers?
- Does the CTA move toward inquiry/inspection/reservation, not empty engagement?
