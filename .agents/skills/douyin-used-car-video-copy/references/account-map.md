## 样本拆解表

每条视频记录：

| 字段 | 记录要求 |
|---|---|
| 基础证据 | 账号、标题、链接、发布日期、时长、互动数据 |
| 开场钩子 | 原句短摘或准确转述；不长期保存大段字幕 |
| 核心冲突 | 价格、车况、需求、选择或人物矛盾 |
| 车型卖点 | 最多三项及其用户价值 |
| 价格锚点 | 历史价、现价、竞品价及口径 |
| 情绪类型 | 惊讶、遗憾、怀旧、爽感、焦虑、温暖、理性等 |
| 目标客户 | 预算、用途、家庭/行业/城市场景 |
| 镜头数量 | 总数及关键镜头顺序 |
| 真人出镜 | 是/否；出镜承担什么功能 |
| 成交故事 | 是否存在；人物、动机、转折、结果 |
| 避坑建议 | 是否存在；证据和风险边界 |
| 硬广程度 | 低/中/高及判断依据 |
| 可复用框架 | 只抽象结构，不复制表达 |
